# User Rating Microservices Application

User Rating Microservices is a backend-based distributed application developed using Spring Boot and Spring Cloud. The project follows a microservices architecture where multiple independent services communicate with each other to manage users, hotels, and ratings efficiently.

## 🚀 Tech Stack
- Java
- Spring Boot
- Spring Cloud
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- PostreSql
- REST APIs
- Eureka Server
- API Gateway
- Config Server
- Resilience4j
- Feign Client
- Maven

## ✨ Features
- Microservices-based architecture
- Service discovery using Eureka Server
- Centralized configuration using Config Server
- API Gateway for routing and filtering requests
- Inter-service communication using Feign Client
- User, Hotel, and Rating service modules
- Secure authentication and authorization
- Fault tolerance and retry mechanism using Resilience4j
- Database integration with MySQL and PostreSql
- RESTful APIs for seamless communication
- Scalable and loosely coupled service design
